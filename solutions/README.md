# Solutions

Reference solutions for the exercises in this repository. Open any solution alongside its source notebook to check your work.

## Learning Path

| Solution | Description |
|---|---|
| [**1 - Principal Component Analysis**](1_principal_component_analysis.ipynb) | Worked answers for the PCA exercise: fit the classifier on raw features versus principal components and compare the accuracy. |
| [**2 - t-SNE**](2_t_sne.ipynb) | Worked answer for the perplexity exercise: recompute the MNIST embedding at two perplexity settings and compare. |
| [**3 - PCA in a Pipeline**](3_pca_in_pipeline.ipynb) | Worked answer for the components exercise: compare test accuracy across different numbers of PCA components. |
| [**4 - PCA, t-SNE and Clustering**](4_pca_tsne_clustering_exercise.ipynb) | Worked answers for the clustering exercise on the Human Activity Recognition data, with the Check Your Understanding questions answered. |
